Welcome! Rust is a systems programming language focused on **safety**, **speed** and **concurrency**. It gives you the control of C and C++ while the compiler rules out entire classes of bugs: null pointer dereferences, use-after-free, data races.

## Who this course is for

You should already know at least one programming language (any of Python, JavaScript, Java, C#, Go, C…). No systems programming background is required.

## What you will learn

1. **Getting Started** — installing the toolchain and using Cargo.
2. **Language Basics** — variables, types, functions and control flow.
3. **Ownership** — the idea that makes Rust unique: ownership, borrowing and slices.
4. **Structs, Enums and Pattern Matching** — modelling your data.
5. **Error Handling** — `Result`, `Option`, the `?` operator and custom errors.
6. **Generics, Traits and Lifetimes** — writing reusable, abstract code.
7. **Collections and Iterators** — `Vec`, `String`, `HashMap`, closures and iterator chains.
8. **Fearless Concurrency** — threads, channels and shared state.
9. **Putting It All Together** — a command-line todo app.

## How to use the sample files

Pages come with `.rs` files attached. Each is a complete program: create a project with `cargo new playground`, replace `src/main.rs` with the file, and run `cargo run`. You can also paste most of them into the online [Rust Playground](https://play.rust-lang.org).

> The compiler is your teacher. Rust's error messages are famously helpful — read them carefully, they often tell you exactly how to fix the problem.
