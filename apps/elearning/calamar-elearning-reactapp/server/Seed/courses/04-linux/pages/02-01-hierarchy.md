# The directory hierarchy

The **Filesystem Hierarchy Standard** describes where things live. Once you know it, you can find your way around any distribution:

| Directory | Contains |
|---|---|
| `/` | the root of everything |
| `/home/<user>` | users' personal files (`~` is a shortcut for yours) |
| `/root` | the root user's home |
| `/etc` | system-wide configuration, as plain text files |
| `/bin`, `/usr/bin` | programs for everyone (on modern distros `/bin` is a link to `/usr/bin`) |
| `/sbin`, `/usr/sbin` | system administration programs |
| `/usr/local` | software you installed yourself, outside the package manager |
| `/opt` | self-contained third-party applications |
| `/var` | data that changes: logs (`/var/log`), caches, mail, databases |
| `/tmp` | temporary files, often emptied at boot |
| `/dev` | device files: disks (`/dev/sda`, `/dev/nvme0n1`), `/dev/null` |
| `/proc`, `/sys` | virtual files exposing kernel and process information |
| `/boot` | the kernel and the boot loader files |
| `/mnt`, `/media` | mount points for temporary and removable media |

## Paths

- **Absolute** paths start at the root: `/etc/ssh/sshd_config`.
- **Relative** paths start at the current directory: `notes/todo.txt`.
- `.` is the current directory, `..` the parent and `~` your home directory.

```bash
$ pwd                 # print the working directory
/home/ada
$ cd /var/log         # absolute
$ cd ..               # up one level: /var
$ cd -                # back to the previous directory
$ cd                  # home
```

## Hidden files

Names that start with `.` are hidden from a plain `ls`. They are usually per-user settings: `~/.bashrc`, `~/.ssh/`, `~/.config/`. Use `ls -a` to see them.

## Exploring /proc

The files in `/proc` are generated by the kernel when you read them:

```bash
$ cat /proc/cpuinfo | head      # CPU details
$ cat /proc/meminfo | head -3   # memory
$ cat /proc/uptime              # seconds since boot
$ ls /proc/$$                   # $$ is your shell's process ID: this is its information
```
