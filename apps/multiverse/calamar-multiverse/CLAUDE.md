# Calamar Multiverse

Let's create an app showcasing various multiverse graphical engines. The idea for each such engine is to offer the user an experience similar to a first-person shooter (but adding the ability to fly too, so the first-person view would actually be that of a small flying drone; this drone would be able to stand still or fly both at a very low speeds, like that of a snail, or at multiple machs - where this would be relevant).

## The layout of our app

Our app should have a top bar that should always be visible (except for full-screen mode that can be exited by pressing the Escape key). In that top bar there will be:
 - a home icon button
 - an icon button for choosing between various graphical engines
 - a settings icon button

Then upon choosing a particular graphical engine to view, the app should navigate to the specific page and let the user experience that.
