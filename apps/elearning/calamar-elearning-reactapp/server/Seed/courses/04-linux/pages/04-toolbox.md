# The Command-Line Toolbox

The power of the shell comes from combining small tools. This chapter covers redirection and pipes, the classic text-processing tools, and shell scripting, from a first script to one that behaves well when things go wrong.

The sample files: `access.log` (a small web server log) with `log-report.sh`, which answers questions about it using pipelines; `hello.sh`, a tour of bash syntax; and `disk-report.sh`, a robust script with options, checks and clean-up.
