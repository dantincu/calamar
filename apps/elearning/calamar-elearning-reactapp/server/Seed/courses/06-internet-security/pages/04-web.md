# Web Application Security

Web applications are the internet's largest attack surface: they're public, they accept input from anyone, and they hold valuable data. This chapter walks through the most important vulnerability classes with runnable demonstrations, and the fixes for each.

Run the demos with Node 22 or later: `node sqli-demo.js`, `node xss-demo.js`, `node password-storage.js` and `node secure-server.js --selftest`.
