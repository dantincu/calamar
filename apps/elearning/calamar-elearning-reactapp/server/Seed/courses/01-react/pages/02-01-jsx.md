JSX lets you write markup inside JavaScript. It looks like HTML, but it is compiled to ordinary function calls.

## Rules of JSX

1. **Return a single root element.** Wrap siblings in a `<div>` or in a *fragment* `<>...</>`:

   ```jsx
   return (
     <>
       <h1>Title</h1>
       <p>Text</p>
     </>
   );
   ```

2. **Close every tag**, including self-closing ones: `<img />`, `<br />`, `<input />`.

3. **Use camelCase for most attributes.** `class` becomes `className`, `for` becomes `htmlFor`, `onclick` becomes `onClick`.

## JavaScript inside JSX

Curly braces open a "window" into JavaScript. You can put any *expression* there:

```jsx
const user = { name: 'Ada', avatar: '/ada.png' };

return (
  <div className="card">
    <img src={user.avatar} alt={user.name} />
    <h2>{user.name.toUpperCase()}</h2>
    <p>{2 + 2} items</p>
  </div>
);
```

Statements such as `if` or `for` can't go inside braces — use them *before* the `return`, or use expressions such as the ternary operator and `map` (next pages).

## Inline styles

The `style` attribute takes an object, with camelCase property names:

```jsx
<p style={{ color: 'crimson', fontSize: 18 }}>Warning</p>
```

The double braces are just an object literal inside a JSX expression.

## Components are capitalized

`<greeting />` is treated as an HTML tag, `<Greeting />` as your component. Always start component names with a capital letter.
