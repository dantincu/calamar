Welcome! This course takes you from your very first React component to a small but complete application.

## Who this course is for

You should be comfortable with modern JavaScript: `let`/`const`, arrow functions, destructuring, the spread operator, modules (`import`/`export`), array methods such as `map` and `filter`, and promises with `async`/`await`. No previous React experience is needed.

## What you will learn

1. **Getting Started** — what React is and how to create a project with Vite.
2. **Components and JSX** — writing components, passing props, rendering lists and conditional content.
3. **State and Events** — making components interactive with `useState`, events, forms, lifting state up and `useReducer`.
4. **Effects and Data** — synchronizing with the outside world through `useEffect`, fetching data and writing custom hooks.
5. **Growing Your App** — context, performance tools, routing, and a final project.

## How to use the sample files

Most pages have **files** attached. They are complete, runnable examples. The easiest way to try one is to create a Vite project (see *Setting up a project with Vite*), copy the file into `src/`, and render the component from `App.jsx`.

> Tip: type the examples yourself instead of copying them. Your fingers learn faster than your eyes.
